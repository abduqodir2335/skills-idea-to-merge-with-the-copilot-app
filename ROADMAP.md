# Bookmark Manager Roadmap

This roadmap builds on the current browser-based bookmark app with organization, management, and portability improvements.

| Area | Item | Type | Priority |
|---|---|---|---|
| Planned features | Search and filter bookmarks | 🚀 | High |
| Planned features | Organize bookmarks with tags | 🚀 | Medium |
| Planned features | Edit and remove individual bookmarks | 🚀 | High |
| Planned features | Import and export bookmark backups | 🚀 | Medium |
| Known bugs & risks | Invalid-URL feedback is limited to a generic status message | 🐞 | Low |
| Known bugs & risks | Slug uniqueness is not coordinated across devices | 🐞 | Medium |

## 🚀 Planned features

- 🚀 Search and filter bookmarks — priority: high
- 🚀 Organize bookmarks with tags — priority: medium
- 🚀 Edit and remove individual bookmarks — priority: high
- 🚀 Import and export bookmark backups — priority: medium

## 🐞 Known bugs & risks

- 🐞 Invalid-URL feedback is limited to a generic status message — priority: low
- 🐞 Slug uniqueness is not coordinated across devices — priority: medium
